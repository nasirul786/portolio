# Arijitiyan — Developer Portfolio

A premium, high-performance developer portfolio built with **Next.js**, **React**, and **TailwindCSS**. Designed with a dark-mode-first aesthetic, featuring vibrant pink glowing accents and sophisticated animations.

## 🚀 Key Features

- **Premium Dark Aesthetic**: Sleek, minimalist design with a signature pink glow (`#eca8d6`) and modern typography.
- **Full Responsiveness**: Every section (Projects, Pricing, Tech Stack) is meticulously optimized for both desktop and mobile devices.
- **Interactive Experiences**:
  - Dynamic **Spotlight Effects** and cursor-following halos on technology cards.
  - Animated **Bioluminescent Scenes** (Whale, Achievements Sphere).
  - Smooth **Framer Motion** transitions and entry animations.
- **Optimized Tech Stack**:
  - **Next.js 16 (Turbopack)** for blazing-fast performance.
  - **TailwindCSS** for flexible, utility-first styling.
  - **Lucide Icons** for clean, consistent iconography.
  - **Slim Scrollbars** customized for all modern browsers.

## 🛠️ Project Structure

- `/components/landing`: Contains all modular sections (Hero, Projects, Process, Skills, Pricing, etc.).
- `/app`: Next.js App Router configuration and global styles.
- `/public`: Static assets including high-quality images and illustrations.

## 📦 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/nasirul786/portolio.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
4.  **Build for production**:
    ```bash
    npm run build
    ```
